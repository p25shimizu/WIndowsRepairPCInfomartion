# PC診断ツール / Windows Repair PC Information Logger

> ⚠️ **INTERNAL USE ONLY / 社内利用限定**

Windows PC の診断・修理・検品・リプレース業務を補助するための、社内向け情報取得ツールです。

## バージョン

- **安定版:** v6.19
- **開発版:** v6.20（GitHub連携・運用テスト）
- **更新日:** 2026-11-17

v6.20では、診断機能そのものではなく、GitHubを利用したバージョン管理・コミット・Pull Request運用の確認を行っています。

## 社員向け：使い方

正式配布開始後は、GitHubのソースコードを直接取得せず、**Releasesに登録された配布用ZIP**を利用してください。

1. GitHubの **Releases** を開く
2. 最新の `PC診断ツール_vX.XX.zip` をダウンロード
3. ZIPを展開
4. `PC診断ツールを起動.cmd` をダブルクリック
5. 初回のみ利用規約を確認して同意
6. 案件番号を入力
7. 「簡易モード」または「詳細モード」を選択
8. 完了後、デスクトップに作成された診断結果フォルダを確認

> 現時点ではGitHub Releaseはまだ正式公開していません。正式配布時にRelease AssetとしてZIPを登録します。

## 簡易モード / 詳細モード

### 簡易モード

通常の検品・リプレース・一次診断向けです。

主な取得対象:

- メーカー / モデル / S/N
- CPU / RAM / ストレージ / GPU
- OS / BIOS
- UEFI / Secure Boot / TPM
- バッテリー情報
- SMART / ストレージ状態
- Windowsライセンス
- Office / Microsoft 365 の簡易検出
- Event Viewer 危険信号
- 主要スペック画像

### 詳細モード

障害解析・原因調査向けです。

簡易モードの内容に加えて、以下を取得します。

- ドライバ情報
- HotFix
- 追加イベント情報
- 稼働時間等の詳細情報
- `msinfo32`
- `dxdiag`

## 主な出力

### 主要スペック1

以下のカテゴリ単位で表示します。

- 本体
- CPU
- メモリ
- ストレージ
- ボリューム
- GPU
- バッテリー
- OS / セキュリティ / Office

### 主要スペック2

SMART / ストレージ状態を表示します。

### ライセンス情報

Windowsライセンス情報を中心に出力します。

Officeについては処理時間短縮のため、詳細な認証キー走査を原則行いません。

### その他

- Firmware / Secure Boot / TPM
- Event Viewer 危険信号
- バッテリー情報
- 診断テキスト
- CHANGELOG

## 重要事項

本ツールの取得・判定結果は**参考情報**です。

実際の仕様、部品構成、増設可否、交換可否、型番、容量、ファームウェア状態、ライセンス状態等は、必要に応じて以下でも最終確認してください。

- 現物確認
- 目視
- BIOS / UEFI
- メーカー公式情報
- 保守資料
- 分解・レビュー情報

本ツールの結果だけを根拠として、修理判断・部品発注・顧客説明・保証判断を確定しないでください。

## セキュリティ

診断結果には、以下の機密情報が含まれる可能性があります。

- S/N
- Windowsプロダクトキー
- Office関連情報
- ネットワーク情報
- イベントログ

**実案件の診断結果や案件フォルダをGitHubへコミットしないでください。**

また、今後SMTP / API / Credential Manager連携等を実装する場合も、以下をソースコードへ直接記載しないでください。

- SMTPパスワード
- APIキー
- アクセストークン
- その他の認証情報

## GitHub運用

開発・更新時は、原則として `main` に直接変更を入れず、バージョンごとのブランチを使用します。

例:

```text
main
  ↑
Pull Request
  ↑
test/v6.20
```

基本フロー:

1. 作業ブランチを作成
2. 変更をコミット
3. Pull Requestを作成
4. 差分を確認
5. 問題がなければ `main` へマージ
6. 正式版の場合はタグ・GitHub Releaseを作成
