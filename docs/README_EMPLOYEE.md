# 社員向け PC診断ツール v6.20 Internal Preview

1. 会社用Google Driveの配布フォルダーから `社内PC診断ツール_v6.20_Preview.zip` をダウンロードします。
2. ZIPをすべて展開します。フォルダー内にある `PC診断ツールを起動.cmd` をダブルクリックします。
3. 案件番号と通常（1）または詳細（2）を選びます。OSを自動判定できない場合は表示されたメニューで選択します。
4. 終了後、デスクトップの `No.<案件番号>-...-PCLog-...` または `No.<案件番号>-PCLog-...` フォルダーを開きます。

`system` フォルダーに入る必要はありません。Windows XP SP3では、案件番号に半角英数字・ハイフン・アンダースコアを使用し、先頭を半角英数字にしてください。

## 診断と販売用の出力

| ファイル | 用途 |
|---|---|
| `No.<案件番号>-PC基本情報.txt` | 本体・主要スペック |
| `No.<案件番号>-ストレージ診断.txt` | ディスク・SMART |
| `No.<案件番号>-BIOS・セキュリティ情報.txt` | BIOS・セキュリティ・ウイルス対策 |
| `No.<案件番号>-エラー・イベント診断.txt` | エラー・イベント |
| `No.<案件番号>-ライセンス情報.txt` | 社内確認用のライセンス情報 |
| `主要スペック.html` / `出品用情報.txt` | 現物と照合してから使う販売資料 |
| `販売前チェック.txt` | 担当者が記入するチェック項目 |

社内の診断ログと既存PowerShell版のPNG画像には、シリアル番号やプロダクトキー等が含まれる場合があります。出品時は、販売用の出力を確認して必要な情報だけ転記してください。XPの `販売用スペック.bmp` は英語ラベルで、ASCII外の文字は `?` で表示されます。日本語の値はHTMLで確認できます。

## 対応OSとモード

- Windows XP SP3では専用のCMDとVBScriptでWMIを照会します。PowerShellは不要です。Systemログは通常モードで過去1日、詳細モードで過去7日のエラーと警告を取得します。
- Windows 7では既存のLegacy PowerShell Collectorを使用します。Windows 8 / 8.1 / 10 / 11ではModern PowerShell Collectorを使用します。
- 取得不可は故障を意味しません。SMART、バッテリー、OEM・ウイルス対策情報などは機種やドライバーによって取得できない場合があります。

本ツールは社内利用限定です。取得結果は現物と照合してください。
