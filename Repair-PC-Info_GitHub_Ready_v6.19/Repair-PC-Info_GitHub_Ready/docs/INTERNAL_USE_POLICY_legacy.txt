Repair PC Information Logger
社内利用規約 / 注意事項
=======================

規約バージョン: 1.0
制定日: 2026-08-14

1. 目的
本ツールは、社内におけるPC診断・修理・検品業務を支援するための
参考情報取得ツールです。

2. 取得情報の位置づけ
本ツールが取得・表示・判定する情報は参考情報です。
実際の仕様、部品構成、増設可否、交換可否、型番、容量、
ファームウェア状態、ライセンス状態等については、
現物確認、目視確認、BIOS/UEFI、メーカー公式情報、保守資料等により
最終確認を行ってください。

3. 自動判定の限界
Windows API、WMI、SMBIOS、ドライバ、メーカー実装等により、
取得結果には誤差、誤検出、取得不能、表記差異が生じる場合があります。
本ツールの結果だけを根拠として、修理判断、部品発注、保証判断、
顧客説明等を確定してはいけません。

4. ライセンス情報
Windows、Office、Microsoft 365等のライセンス認証情報、
プロダクトキー等は機密情報として扱ってください。
不要な共有、社外送付、公開は禁止します。

5. 利用範囲
本ツール、本ツールのソース、生成されたログ、画像、レポート等の利用は
社内業務に限定します。
社外への配布、再配布、公開、転載、個人利用、第三者提供は禁止します。

6. 社外提示
顧客または社外関係者へ資料を提示する場合は、
シリアル番号、プロダクトキー、メールアドレス、ネットワーク情報等の
機密情報・個人情報が含まれていないことを事前に確認してください。

7. 改変・派生版
本ツールの改変版・派生版を社外へ持ち出すことは禁止します。
社内での変更・更新は、管理担当者の管理のもとで行ってください。

8. 利用者責任
本ツールの利用者は、出力結果をそのまま最終判断とせず、
業務上必要な追加確認を行ったうえで利用してください。
